# KubeJS Editor

[![构建检查](https://github.com/meizuishan/kubejs-editor/actions/workflows/build.yml/badge.svg?branch=main)](https://github.com/meizuishan/kubejs-editor/actions/workflows/build.yml?query=branch%3Amain) · [下载 0.18.0 测试版](https://github.com/meizuishan/kubejs-editor/releases/tag/v0.18.0)

**游戏内 KubeJS 可视化配方与内容编辑器。** 面向 Minecraft **1.21.1 / NeoForge**，当前测试版 **0.18.0**。

从 JEI 拖入材料和产物，修改机器配方、注册物品和方块。编辑器生成标准 KubeJS 脚本，并提供待办、检查、备份、批量撤销和回滚。强制兼容采用通用来源读取和字段补丁，尽量复用模组已经公开的数据接口。

## 功能

- **配方编辑**：新增、替换、禁用已有配方；支持 JEI 拖放、数量、组件、概率及原生参数。
- **Create 集成**：常见加工设备画布、动力合成、序列组装和部分附属加工。
- **内容注册**：物品、食物、工具、防具、常用方块、单格耕地作物与可配置存储方块。
- **通用字段补丁**：修改原始字段、物品／流体 ID、组件、数值和列表；支持精确批量替换、预览、撤销及原生格式检查。
- **自动选择适配方式**：按实际来源、槽位覆盖、字段和规则问题比较候选；保留已确认的手动映射。
- **修改管理**：自动保存待办、代码与差异预览、一次重载的批量撤销、文件冲突检查和失败回滚。
- **配置编辑**：读取模组公开的配置定义，区分全局机器设置与单条配方参数。

## 强制兼容的能力界限

**强制兼容不是任意模组机器的通用改写器。** 它优先寻找普通配方、公开包装来源、完整编码匹配或原生数据包注册表，再选择覆盖较完整的编辑方式。

- 有真实可写来源时，可绕过编辑器尚未认识的槽位／字段，直接按原生格式修改；未知字段、标签、组件与独立数量尽量保留。
- 原生 Codec、实际注册项和加载结果仍决定修改是否有效。仅修改 JEI 展示对象不能改变机器加工。
- 来源有歧义时需要确认。手动选择真实数据源并不自动证明它与当前 JEI 展示关联；修改可能影响所有共享该来源的机器。
- 配置或硬编码计算、私有管理器、共享战利品等机制，不保证能作为普通配方编辑；本版不提供任意 Java 逻辑／私有字段写入。
- 普通配方通常通过重载生效；原生数据包注册表、内容注册及部分配置需要重启。原生注册表覆盖数据需要保留兼容版本的编辑器。
- 直接应用面向本机单人世界／集成服务端，不提供远程服务器写入。完整行为与限制见 [通用补丁说明](docs/GENERIC_PATCHES.md)。

## 开始使用

1. 关闭游戏，安装主 Jar 及匹配的 KubeJS、Rhino、JEI；同一实例只保留一个编辑器版本。发布包附有 PowerShell 7 安装器，可备份旧 Jar。
2. 进入世界按 **K**，或执行 `/kubejseditor`（别名 `/kjseditor`）。
3. 从 JEI 配方按钮进入，或在最后一栏 **强制兼容** 选择机器／配方。
4. 修改后检查待办和代码差异，再一键应用。批量撤销位于 **已有修改 → 批量删除**。

原始字段入口：**更多 → 通用字段补丁**。自动方式入口：**更多 → 适配方式（自动优选）**。

存储支持 **1～9 行、1～12 列、单格 1～4096**，默认 3×9、64/格；不可堆叠物品每格仍限 1，提取与掉落按正常堆叠拆分。存储注册脚本运行时需要保留本模组。
