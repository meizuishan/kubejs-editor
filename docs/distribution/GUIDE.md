# 使用说明

## 开始编辑

1. 关闭游戏并安装主 Jar 与所需依赖；进入世界按 K 或执行 /kubejseditor。
2. 从 JEI 配方页的编辑按钮进入，或在最后一栏“强制兼容”拖入机器，选择分类和配方。
3. 点击已绑定槽位编辑，或从 JEI 拖入材料、流体与产物；右侧编辑数量、概率及可识别参数。
4. 查看待办、代码与差异，检查后“一键应用”。应用前自动保存待办，并检查文件冲突。

主栏包括“新增功能”“修改现有”“机械动力”“已有修改”“强制兼容”。配方列表来自当前世界实际加载的数据；能展示的配方未必都有可写来源。

## 字段映射

字段确认默认初级模式：输入格、输出格、催化剂、数值修改、条件修改。输入与输出可区分物品、流体和其他原料；高级模式可查看原始路径、单位、数量包装及复杂结果。

已有 JEI 格子可左键选中，再选择字段；也可先选字段再点格子。自绘区域支持框选。一个字段可关联多个位置；同格多候选按原生格式支持 OR。无法正确编码的类型保留只读。

“清空映射”并保存表示取消现有映射；“重置映射”恢复自动读取。已确认的手动映射优先于自动选择。

## 通用字段补丁

进入“更多 → 通用字段补丁”，搜索原始字段，修改值、增加或删除列表项，也可使用 JSON Pointer／Patch。物品与流体 ID 字段支持 JEI 拖放；数量及组件分别编辑。

先预览差异，再“检查并保存补丁”加入待办。此时不会立即重载。原生校验拒绝时保留原草稿，可以继续修正。“更多 → 适配方式”可查看候选、指定方式或恢复自动优选。

无自动来源时可以手动浏览真实配方、数据包注册表或公开配置。手动选择表示明确修改该数据，不自动证明其与当前 JEI 展示关联；共享数据可能影响多台机器。

## 撤销与回滚

待办左侧 × 取消未应用修改。已生效内容从“已有修改 → 批量删除”筛选、多选并统一撤销：普通配方只重载一次，包含注册时统一等待重启。

撤销替换或禁用规则后恢复原来源；撤销新增规则后移除新增配方。失败时保留记录，按照诊断处理或回滚。不要直接覆盖手写脚本和玩家文件。

## 注册与存储

“新增功能”可创建物品、食物、工具、防具、常见方块、单格耕地作物及存储方块。作物含种子、阶段材质和掉落设置。

存储为 1～9 行、1～12 列、单格 1～4096，默认 3×9、64/格，最多 108 格。不可堆叠物品每格限 1；提取和掉落按物品正常堆叠上限拆分。存储注册脚本运行时需要保留本模组。

已生效注册的类型、作物阶段数和存储结构固定，改变结构时使用新 ID。注册及部分配置需要重启。

## 诊断

只读详情会说明未识别、来源有歧义或缺少写入接口等原因。“更多 → 最近诊断”可查看错误。反馈时提供模组与依赖版本、配方 ID、操作和错误文字，注意删去个人信息。
