# 版本范围与兼容边界

| 项目 | 声明范围 |
|---|---|
| Minecraft | 仅 1.21.1 |
| Java | 21 |
| NeoForge | [21.1.199, 21.2) |
| KubeJS | 2101.7.2-build.368 起，满足其自身依赖 |
| Rhino | 使用与 KubeJS 匹配的版本 |
| JEI | 客户端 [19.25.0.322, 20) |
| Create | 可选；集成声明 [6.0.10, 6.1) |

依赖范围不能任意交叉组合。例如 JEI 19.57.0.449／19.69.0.457 自身要求 NeoForge 21.1.238 起。Forge、Fabric 和其他 Minecraft 版本不适用。

## 验证范围

0.18.0 已通过 613 项回归、39 组序列化样例、五组代表性构建和 270 项最终隔离客户端检查。Windows／Linux 的代表构建组合覆盖最低 JEI 19.25、19.27、19.57 和 19.69；构建通过不等于所有机器均已实测。

本版未全面重测物理机器实际消耗、多人及原生注册表真实 JVM 重启循环，不承诺所有整合包与依赖组合均兼容。

## 强制兼容的边界

- 自动读取普通配方、公开包装来源、原生数据包注册表和已确认的字段映射，优先选择覆盖更完整的方式。
- 编辑所需的是服务器实际使用的可写数据。纯展示、硬编码加工、私有管理器和共享战利品机制不保证可编辑。
- 原生 Codec、组件、标签、数量与实际加载结果决定修改有效性；未知字段可以保留，但不保证机器会使用它。
- 来源有歧义时需要确认。共享来源的修改会影响全部使用者；全局机器配置也不同于单条配方的能量或时间。
- 普通配方通常可重载；注册、原生数据包注册表和部分配置需要重启。原生覆盖需要保留兼容版本的编辑器。
- 直接应用支持本机单人世界／集成服务端；远程服务器写入不在本版支持范围内。
